# ThermalPrint Studio

Un logiciel web pour piloter n'importe quelle imprimante thermique (ESC/POS) depuis un navigateur.

## Fonctionnalités

- Détection automatique des imprimantes (USB / Série / Réseau)
- Statut temps réel (papier, capot, erreurs)
- Import PDF → conversion automatique en ticket thermique
- Éditeur de ticket (logo, articles, totaux, QR code, code-barres)
- Historique d'impression & ré-impression
- Interface web moderne (FR, thème clair/sombre)

## Stack

- **Backend** : FastAPI + python-escpos + Pillow
- **Frontend** : Next.js + Tailwind + shadcn/ui
- **Temps réel** : WebSocket (statut imprimante)
